# Trang Chủ & Tích Hợp Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng hoàn chỉnh giao diện Trang chủ (`/`) và tích hợp logo chính thức của dự án (`public/images/logo.png`) theo chuẩn `DESIGN.md`, tuân thủ triệt để Hallmark design discipline (chống AI slop, trung thực, thanh mảnh nhẹ nhàng, mobile-first, 1 font duy nhất Be Vietnam Pro).

**Architecture:** Trang chủ là Server Component (`src/app/(site)/page.tsx`), sử dụng các UI primitives (`Container`, `Section`, `Heading`, `Kicker`, `Card`, `LinkButton`, `Notice`) và layout components (`Header`, `Footer`). Tích hợp `public/images/logo.png` vào Header, Footer và Hero. Lấy dữ liệu tĩnh từ `src/data/plans.ts`, `src/data/drinks.ts`, `src/data/articles.ts`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript strict, Tailwind CSS v4, Lucide React (`strokeWidth={1.75}`), Vitest.

**Spec:** `docs/superpowers/specs/2026-10-10-home-page-design.md`

## Global Constraints

- Duy nhất 1 font chữ: `Be Vietnam Pro` qua `next/font`.
- Trọng số thanh mảnh: `300`, `400`, `500`, `600`. Tuyệt đối không dùng `font-bold` (700+).
- Không cỡ chữ quá to quá thô. Tiêu đề lớn nhất `3xl` (`1.875rem` / `30px`).
- Câu chữ ngắn gọn súc tích, sentence case tiếng Việt, xưng hô "mình"/"bạn", không làm vỡ layout.
- TUYỆT ĐỐI CẤM emoji và cấm dùng text thay icon. Biểu tượng duy nhất từ `lucide-react` nét mảnh 1.75.
- Không dùng mã hex thô hay trắng tinh `#fff` / đen thuần `#000`. Chỉ dùng tokens từ `globals.css`.
- Dữ liệu tĩnh: Tối đa 2 thức uống, 3 liệu trình, 1 bài viết mẫu. Không gọi mock API.
- Tap target mobile ≥ 48px, mobile-first chuẩn 390px.
- Không tự ý commit git khi chưa được người dùng cho phép trực tiếp.

## Review Focus

1. Hiển thị logo chính thức mượt mà, không bị vỡ ảnh hay méo tỷ lệ (dùng Next.js `Image` với width/height tường minh).
2. Kiểm tra giao diện trên mobile 390px không bị tràn ngang (`overflow-x: clip`).
3. Đảm bảo toàn bộ tiêu đề là roman đứng (`font-style: normal`), không có tiêu đề italic.
4. Nút bấm CTA "Xem lộ trình của tôi" điều hướng chính xác về `/consultation` với tap target ≥ 48px.
5. Thẻ card không lồng nhau và viền hairline 1px `#E6DFD2` đồng nhất.
